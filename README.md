# Vitex Portfolio

## Contact form

The React contact form uses [`@formspree/react`](https://github.com/formspree/formspree-js/tree/master/packages/formspree-react) and submits to Formspree form `mnpdgpdr`. Formspree handles delivery, so this site does not need a contact API route or email service secrets. Confirm the form's recipient and allowed domains in the Formspree dashboard before deploying.
